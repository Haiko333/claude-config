# Development Workflow

Scale the process to the task.

## Small change (fix, config, script, one or two files)

Read the code, make the change, verify it runs, done.

## Feature (several files or new behavior)

1. **Reuse first** — check the codebase, the standard library, and installed dependencies before writing new code or adding a package.
2. **Plan** — a short list of steps in the conversation. Planning docs only if asked.
3. **Implement with tests** — see [testing.md](./testing.md).
4. **Review** — see [code-review.md](./code-review.md).
5. **Commit** — see [git-workflow.md](./git-workflow.md).

## Before requesting PR review

CI passing, no merge conflicts, branch up to date with target.
